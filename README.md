# Shrines Reborn

Port of [Shrines Structures](https://github.com/Silverminer007/Shrines) by Silverminer007 to Minecraft 1.21.1 (NeoForge and Fabric).

Adds 30 structures to world generation: temples, shrines, villas, towers, a harbour, a balloon and more, across the overworld, the Nether and the End. Vanilla structures are left alone.

The mod id (`shrines`) and all structure and loot table ids are the same as the original, so datapacks and configs that reference them keep working.

## Building

```
./gradlew buildAll       # all versions
./gradlew gameTestAll    # places every structure and rolls every loot table
```
